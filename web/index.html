Planetary Lore // Aethelgard

The Great Desynchronization

Centuries ago, the automated civilization of Aethelgard collapsed when its operating engineers deployed Kernel Zero — a control system plagued by unsafe pointers, unconstrained data races, and unmetered loops.

Foundries melted down, automated trains collided, and toxic chemical storage ruptured. The surviving planetary security intelligence, The Ferric Arbiter, severed physical control relays and quarantined all machinery.

The Arbiter requires firmware written with mathematical safety guarantees: no null pointers, zero data races, bounded execution budgets, and strictly enforced linear resource custody.

Systems Architecture

Engineered Without Shortcuts

Rustbound combines modern game engine architecture with real systems engineering tooling.

🦀

Real rustc Integration

No fake interpreted mock scripting. Player code is dispatched to the genuine rustc toolchain targeting wasm32-unknown-unknown with real compiler diagnostics parsed and rendered into in-game code spans.

⚡

Wasmi 2.0 VM Runtime

Bytecode runs inside an isolated, fuel-metered WebAssembly virtual machine. Infinite loops trap before exceeding the 50,000 instruction budget, and out-of-bounds pointer accesses trigger deterministic FFI runtime traps.

🎮

Bevy 0.20 CAD Visualizer

Built on Bevy 0.20 with an isometric CAD-style orbit camera (orbit, pan, zoom, keyboard WASD), raycast machine picking, PBR graphite plating, and real-time telemetry meters.

📦

Linear Types as Physical Tokens

Resources in transit are represented as ResourceChunk<T> linear types. In Rust, values cannot be dropped or cloned silently — enforcing that physical resources are moved safely between machinery intakes with zero physical leaks.

⏱️

20 Hz Deterministic Headless ECS

The simulation core is decoupled from rendering and windowing. It enforces #![deny(clippy::float_arithmetic)], integer coordinates TileCoord(i32,i32,i32), and a 60-tick ring buffer for rewinding and replaying.

🔌

POD Binary FFI Protocol

High-performance C-ABI FFI communication using zerocopy 0.8 Plain Old Data (POD) structs. Zero dynamic memory allocation overhead across guest and host boundaries.

Developer Setup

Launch On Your Machine

Requires Rust 1.85+ with wasm32-unknown-unknown installed.

# 1. Clone the repository
git clone https://github.com/jyothiprajith1323/Rustbound.git
cd Rustbound
# 2. Add the wasm32 compilation target
rustup target add wasm32-unknown-unknown
# 3. Precompile the player API SDK
cargo build --release --target wasm32-unknown-unknown -p rustbound_api
# 4. Run the 33-test verification suite
cargo test --workspace --jobs 1
# 5. Launch the 3D client
cargo run --bin rustbound
